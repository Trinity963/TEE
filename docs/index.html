What it does

One Router. All Models.

TEE sits between your applications and your local models. It handles backend selection, GPU placement, model registration, and inference routing — so nothing else has to.

Everything else calls TEE. TEE calls nothing external.

Your App  ──▶  TEE  ──▶  llama.cpp / vLLM / Ollama  ──▶  GPU  ──▶  Your Model
OpenAI-compatible API  ·  No cloud  ·  No accounts  ·  No keys

Any application that speaks the OpenAI protocol works with TEE immediately — zero changes required. Point your existing tools at localhost:8765 and they work.

Features

Built for Sovereignty

⬇
Hot-Drop GGUF
Drop any GGUF into a watched directory. TEE reads the header, generates the modelfile, and registers the model. No commands. No config.
◎
Ollama Adapter
TEE auto-discovers all models served by your local Ollama instance. GGUF and Ollama models appear unified in the same registry.
▣
Sovereign UI
Built-in browser dashboard. GPU VRAM bars, live model registry, config viewer. Pure Python + vanilla JS. No CDN. No dependencies.
⬡
Hardware Intelligence
TEE reads your GPUs on startup. It knows what fits, what needs multi-GPU, and what exceeds your VRAM — before it tries to load anything.
◈
Multi-Directory
Watch multiple model directories simultaneously. NVMe, HDD, external drives, NAS. TEE sees all of it and manages it as one unified registry.
⟳
Idle Unload
Models unload automatically after idle timeout. VRAM is reclaimed without intervention. Load the next model without rebooting anything.
◉
Live Log Stream
Real-time log panel on the dashboard. Every gateway request, model registration, and runtime event — live, color-coded, pauseable.
⬇
HuggingFace Downloader
Download any GGUF directly from HuggingFace via the UI. Live progress bars. Auto-registers the model when complete. No CLI required.
⟁
OpenRouter Adapter
21 free-tier cloud models — MiniMax M3, Nemotron Ultra 550B, Gemma 4 — unified in the same registry as your local models. One API. Zero cost.
Quick Start

Up in 60 Seconds

# Clone
git clone https://github.com/Trinity963/TEE.git
cd TEE

# Configure
cp tee.config.example tee.config
# Edit tee.config — set your models_dirs path

# Run — one command starts everything
python3 tee.py
# Gateway on :8765  ·  Sovereign UI on :8766  ·  Ollama adapter live

TEE starts, scans your model directories, registers everything it finds, and begins serving on http://localhost:8765/v1/

Sovereign UI opens on http://localhost:8766/
